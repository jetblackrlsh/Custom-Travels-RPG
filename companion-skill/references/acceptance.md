# Adventure acceptance worksheet

Record adventure ID/version and engine version. For each of nine abilities, record scene/action ID, eligibility, charge cost, outcome, and a tested reachable route. Check both success and failure for rolled actions.

Run all five premades. Add a legal custom character with unused skills, a different appearance, and each ability selection combination relevant to coverage. Confirm unused skills do not block entry.

Test a zero-magic route, an exhausted-charge route, an injured character, enemy defeat before retaliation, player defeat, and branch flags that affect an ending. Document any intentional one-attempt actions.

Export/import the character into another adventure without losing appearance, stats, or selections. Save/reload mid-adventure without changing HP, charges, choices, flags, or rolls already resolved.

Review the actual illustration and puppet pose. Check the packaged browser file opens offline where a supported browser is available. Distinguish real-browser checks from simulated DOM checks. Review license attribution and ensure no reference game's proprietary assets slipped into the package.

- [ ] New encounter outline is original rather than a lightly reskinned prior example.
- [ ] Scene/state illustrations match current actors, conditions, location and prop ownership.
- [ ] Every ending and important combat-damage state visually reviewed.
- [ ] Player feedback and any untested limitations recorded without inflated claims.
